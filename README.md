# 🎓 Predictive Analysis of Student Performance in Online Learning

## 📌 Project Overview

This project predicts student performance in online learning environments using Machine Learning and visualizes key insights through Power BI dashboards. The goal is to identify at-risk students, analyze engagement, and help improve academic outcomes using data-driven decision-making.

---

## 🎯 Objectives

- Predict student performance using Machine Learning.
- Identify students at risk of poor academic performance.
- Analyze student engagement and learning behavior.
- Visualize performance trends using Power BI.
- Support educational institutions with actionable insights.
